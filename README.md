# Spring Security - 3 ví dụ

Đã điều chỉnh từ project tham khảo được cung cấp. Bắt đầu với **HUONG_DAN_STS.md**.

- SQL Server: localhost:14330, login sa.
- Điền mật khẩu DB trong .env của từng ví dụ; chạy database/create_all_databases.sql trước.
- Import 3 project Maven vào STS; Run As > Spring Boot App.
- Web: 8080 / 8081 / 8082.
- Admin web: admin@uteshop.vn / Admin@12345.
- Kết quả kiểm tra cụ thể: THONG_TIN_CHAY_THU.txt.
- Cấu hình email/Cloudinary thật nằm trong hướng dẫn; mặc định OTP là demo.
